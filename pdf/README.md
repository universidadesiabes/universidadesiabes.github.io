# Materiais em PDF

Um PDF por aula (por tópico), referenciado em `config/cursos.js` (campo `pdf` de cada aula) —
o mesmo recorte por tópico usado nos vídeos em `Documents\Projeto Universidade\video aulas\cortados\`:

- `modulo-1/01-o-que-e-o-scfv.pdf` ... `modulo-1/06-boas-praticas-de-gestao.pdf`
- `modulo-2/01-atendimento-no-domicilio-e-o-pdu.pdf` ... `modulo-2/08-agendamento-e-frequencia.pdf`

Antes, era 1 PDF só por módulo (cobrindo todos os tópicos) — foi trocado porque o botão
"Baixar" de cada aula acabava entregando o material inteiro do módulo, não só o do tópico
que a pessoa estava assistindo.

Se o conteúdo de algum tópico mudar, peça pro Claude regenerar o PDF correspondente (o
texto-fonte de cada tópico está descrito nesta conversa/no histórico do projeto).
