# Materiais em PDF

Coloque aqui os PDFs referenciados em `config/cursos.js` (campo `pdf`):

- `Material_Didatico_Aula1.pdf`
- `Material_Didatico_Aula2.pdf`

Exporte os `.docx` correspondentes como PDF (Word → Salvar como → PDF, ou Google Docs → Arquivo → Fazer download → PDF) e salve aqui com esses nomes exatos — o botão "Baixar" da tela de aula já aponta para eles.
